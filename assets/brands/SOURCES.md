# Visual assets and provenance

The profile intentionally uses local SVG assets, avoiding externally hosted badges and image services.

- **Brand icons and selected technology marks**: [Simple Icons](https://github.com/simple-icons/simple-icons) (CC0, subject to respective trademarks).
- **Interface icons**: [Lucide](https://lucide.dev) (ISC license).
- **Codex mark**: [Devicon](https://github.com/devicons/devicon/blob/master/icons/codex/codex-plain.svg).
- **Google Antigravity / Claude Code marks**: [Lobe Icons](https://github.com/lobehub/lobe-icons), used in monochrome.
- **T3 Code mark**: [T3 Code brand icon](https://github.com/pingdotgg/t3code/blob/main/assets/prod/app-icon.icon/Assets/text.svg).
- **SVG layouts**: Custom theme-specific hero, technology chips, activity panels and contribution calendars maintained in this repository.

The profile remains usable when GitHub Actions is delayed; committed activity SVGs are regenerated by the daily workflow.
