### About

I'm Mello, a software developer, business owner and technology enthusiast from Brazil. I like turning ideas into useful software, understanding how things work, and paying attention to the details that make products feel right.

I'm especially interested in **developer experience, intelligent systems, automation, web platforms and thoughtful UI**. I build to solve practical problems, learn along the way and create things I'd genuinely want to use.
