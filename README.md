### Sobre mim

Estudante de **Engenharia de Software** (UNINTER) aprendendo na prática — construindo APIs, estudando arquitetura e tentando escrever código cada vez mais limpo.

Comecei pela IA com Python e desde meados de 2025 venho me aprofundando no ecossistema **Node.js + TypeScript**, passando por Clean Code, SOLID, DDD e testes.
